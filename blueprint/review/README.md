# Internal review records (not part of the publication)

This folder keeps the records of the pre-publication review of the BAPIL Technical Blueprint for traceability. None of these files is part of the published Blueprint, and none is included in the Zenodo package.

| File | What it is |
|---|---|
| `BAPIL_Blueprint_Audit_and_Revision_Report.md` / `.pdf` | Audit of the pre-publication draft: issue register (I-01 to I-41), claim verification, budget reconciliation, scores and publication checklist |
| `BAPIL_Blueprint_Adversarial_Review.md` / `.pdf` | Independent adversarial review of the revised draft: defects R-01 to R-25 with corrected passages, weighted score and readiness verdicts |
| `BAPIL_Blueprint_Prepublication_Change_Record.md` | The change record that was Table 68 of the draft; moved here so that the publication does not present itself as a revision report |
| `build_report.sh`, `header-review.tex` | Build script and header for the two review PDFs |

The corrections made in response to these reviews, and in the final production stage, are listed in `../CHANGES.md`. The file names are kept unchanged so that the development history remains traceable.
